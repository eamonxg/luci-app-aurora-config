# Aurora Config 两页重构设计（设置工作台 + 主题商店）

日期：2026-08-04
状态：已定稿（用户逐项确认）
关联原型（会话内，阅后即弃）：`theme-store-ui-prototype.html`（商店三选一 → 网格市场）、`aurora-config-redesign.html`（设置三选一 → 工作台）、`aurora-config-themed.html`（按真机琥珀沙外观复刻的终版对比，工作台胜出）

## 背景与目标

1.1.3 引入主题商店后暴露三类问题：

1. **性能**：hub 请求走 浏览器 → ubus → rpcd shell → 路由器 `wget` → Cloudflare，国内路由器到 CF 线路差 + Worker 冷启动 + 8s/12s 超时兜底，列表和详情都"加载很久"；同接口浏览器直连约 0.75s。
2. **可用性**：路由器出网不稳时商店整页报 `hub_unreachable`。
3. **信息架构**：内置预设与商店重复（两套入口、两套应用交互）；设置页顶部挤 6 个控件；字体库/素材库两套上传交互；30+ 派生色平铺压迫普通用户。

## 已拍板决策

| 决策 | 结论 |
|---|---|
| hub 请求路径 | 浏览器直连（读+写），rpcd 只做本地事务，路由器零出网 |
| 页面结构 | **两个独立 view + LuCI 原生 tabmenu**：`aurora/theme`（设置）、`aurora/gallery`（商店）；menu.d / ACL 不动 |
| 商店 UI | 网格市场（卡片网格 + 右侧详情抽屉） |
| 设置 UI | 工作台（左手风琴控制面板 + 右实时预览 + 底部保存条） |
| 视觉语言 | 沿用现行 Aurora 主题：下划线式 tabmenu、胶囊按钮、大圆角卡片、状态徽标；不引入新设计语言 |
| LuCI API 边界 | 保留 `view.extend`/menu/ACL/`rpc.declare`/`L.uci`/`ui.changes`/`_()`/`E()`；**两页均退役 `form.Map`**（theme.js 现状：form 选项仅 ~10 个，自定义 E() 已有 81 处） |
| cbi-tab（form 内分区标签） | **移除**：职责由手风琴取代（原三 tab 中两个是容量不够导致的领域合并）；亮/暗等细粒度切换改分段控件；语义匹配处沿用 `.cbi-button`/`.cbi-section` 等通用类名，保证非 Aurora 主题下的样式退化 |
| 独立 SPA | 否决（认证/CSRF/i18n/菜单/主题一致性代价高，所需能力自定义视图已具备） |
| theme.js 预设下拉 | 删除，商店"内置"分组承接；`apply_theme_preset` RPC 保留为内置应用路径 |
| theme.js "恢复默认" | 保留（安全网），收进溢出菜单 |

## 架构：请求边界

| 操作 | 路径 | 说明 |
|---|---|---|
| 列表 / 详情 | 浏览器 → hub | `hub-api.js` 从 `rpc.declare` 改为 `fetch` |
| 应用（在线主题） | 浏览器取 payload → POST rpcd `hub_apply_payload` | 本地严格校验 + uci batch 不变，防注入原样保留 |
| 应用（内置） | `apply_theme_preset` | 不联网 |
| 素材落盘 | 浏览器从 hub 下载 → 现有上传通道交给 rpcd | 按 payload sha256 校验后才安装 |
| 分享 / 更新 / 删除 | 浏览器直连 hub | token 由 rpcd `get_device_identity`（ACL 保护）提供；管理员浏览器本就有 root 级 RPC 权限 |

**rpcd 瘦身**：删除 `fetch_url`、`hub_http_*`、异步 job（`hub_apply`/`get_hub_status`）及各 hub_* 的网络部分；新增 `hub_apply_payload`（同步：备份→校验→uci→安装已上传素材）、`get_device_identity`、`hub_build_share_payload`（从本地 uci+素材构造分享 payload）；保留 `hub_restore_backup`。

**Worker（themes-hub）**：全部 `/api/v1/*` 与素材响应加 CORS（`Access-Control-Allow-Origin: *` + OPTIONS 预检，实测目前 404）；官方 seed 数据补 `builtin_id` 字段（条目 id 是随机串，前端靠它与内置去重）。

## 设置页规格（工作台，theme.js 重写）

**布局**：左 ~320px 控制面板（手风琴分组）+ 右实时预览画布 + 底部粘性保存条（"● 有未保存的更改 · 放弃 / 保存并应用"，接 `L.uci` + `ui.changes` 语义）。窄屏时上下堆叠，画布收成可展开预览条。

**手风琴分组**（每组标题右侧显示当前状态摘要）：

1. **配色**：快速换整套色卡（内置 5 套，点击即预览；"更多去商店"链接）→ 4 源色取色器（亮/暗分模式）→ "微调派生色"二级入口（默认折叠，普通用户只见 4 源色）。
2. **布局**：导航样式三选卡片（带迷你示意图：mega / dropdown / sidebar）、间距滑杆、圆角滑杆、内容宽度。
3. **字体**：正文/等宽两个槽位卡（字体名 + Aa 标本 + 下拉换 + 直接上传 .woff2），**取消独立字体库表格**。
4. **品牌**：6 槽位网格（Logo / Favicon / 触屏图标 / App 图标 ×2 / 登录背景），槽位直传 + 缩略图，**素材库管理降为溢出菜单二级入口**。
5. **快捷工具栏**：总开关 + 行编辑（拖拽排序、标签、**页面从 LuCI 菜单树选择**——不再手输 URL、图标选择）。

**溢出菜单（⋯）**：导出配置 / 导入配置 / 管理已上传素材 / 恢复出厂默认。版本号（theme/config）移到页脚小字。

**实时预览双通道**：

- 主通道：设置页运行在 Aurora 主题内，改动写 `:root` CSS 变量，**真实页面即预览**（顶栏/侧栏/面板即时变化）。
- 合成画布：右侧 mini 预览只负责当前看不到的场景——暗色模式、登录页（含背景图）、另两种导航布局；按真实 uci 值渲染。
- 降级：检测不到 Aurora 主题变量（用户切了别的主题）时，隐藏实时通道，显示"保存后在 Aurora 主题下生效"。

## 商店页规格（网格市场，gallery.js 重写）

- 工具栏：搜索（本地过滤）+ 分段标签：全部 / 内置 / 热门 / 最新 / 我的分享。
- 卡片：迷你预览（16:9 左亮右暗对分）+ 名称 + 徽标（内置/官方/含素材）+ 作者 + 底行（色点 ×4、导航类型、下载数或"离线可用"）；悬停浮起 + "应用"快捷按钮。
- 详情抽屉：右滑 440px；大预览（亮/暗切换）+ 描述 + 色板 chips + 布局/字体/素材清单 + 应用须知 + "应用此主题"。
- 应用交互：内置与在线统一走"应用 → 顶部一键回滚 banner"。
- 内置分组：包内 presets 本地渲染，离线永远可用；hub 官方 seed 按 `builtin_id` 去重隐藏。
- 状态：首屏 localStorage 缓存立即渲染 + 后台刷新；hub 不可达时仅显示内置分组 + 顶部降级提示，不再整页报错。

**迷你预览组件**（两页共用）：按色板绘制的假 LuCI 页面；按 `nav_type` 画对应结构；圆角/间距映射；Logo 有则注入顶栏；标题条换真实短文字以体现字体。

## 缩略图三层

- **L1 卡片级**（零/低网络成本）：色板绘制 + 布局结构 + logo 小图 + "Aa 字体名"标本（本机无该字体时诚实回退）+ 徽标。App 图标类不上卡片，只进详情。
- **L2 悬停翻面**：含登录背景的主题翻转为迷你登录页，用分享时生成的缩略图。
- **L3 详情级**：登录背景全图；自定义字体 `@font-face` 从 hub 懒加载真渲染。
- **分享 payload v2**：分享流程在浏览器执行，上传 `login_bg` 时 canvas 生成 ~480px WebP 缩略图一并上传；payload 增加 `typography.font_display_name` 与素材 `thumb` 引用。旧数据无 thumb → 无翻面，仅详情懒加载，不迁移。

## 实施笔记（2026-08-04，Phase 3 v1 落地后补记）

- **Phase 1/2/3 已完成并推送 `wip/theme-store`**；Phase 4/5 未开始。
- Phase 3 实际落地为 **v1：呈现层重构、数据层保留 form.Map**。理由：theme.js 的 form 绑定面远大于评审时估计（62 个颜色选项 + 字体准备/资产上传/工具栏 Grid 的自定义 load/write/render 覆盖），整体退役 form.Map 的回归风险远大于收益。cbi-tab 已按决策退役（外层三 tab → 原生 `<details>` 手风琴五分组：配色/布局/字体/品牌/快捷工具栏），头部瘦身（版本徽标→页脚、导出/导入/重置→⋯溢出菜单、商店入口链接）、右侧预览画布（亮/暗切换、随 nav_type 变结构）、`.cbi-page-actions` 粘性化如期落地。
- 与 spec 原文的差异，留待 v2：画布随保存刷新（实时通道仍是页面本身的 CSS 变量预览）；配色组内亮/暗仍是内层 tab（未改分段控件）；品牌"槽位直传"未做（素材库表格仍在品牌组内）；手风琴标题无状态摘要。
- 结构兜底：工作台装配若检测到小节块数不符合预期（<6），直接回退渲染原始 map，布局永不牺牲功能。
- 迷你预览抽成共享模块 `utils/theme-preview.js`（商店与工作台共用，hex 消毒集中一处）。

## 分期实施（每期独立可发布、可回退）

1. **Phase 1 — 性能**：Worker 加 CORS；hub-api.js 列表/详情改浏览器直连（应用暂留旧路径）。

## 风险

- `Access-Control-Allow-Origin: *`：hub 读接口本就公开；写接口鉴权在 token，不受影响。
- form.Map 退役后失去表单校验/依赖机制：这 10 个选项均为枚举/滑杆，手写校验成本可忽略。
- 浏览器直连要求管理端能访问 hub：比"路由器能访问"更弱的假设；完全离线由内置分组兜底。
- 大字体文件经浏览器中转上传：沿用现有上传通道进度提示。
